# Palo Alto Firewall Labs

A hands-on learning repository for Palo Alto Networks firewall administration, network security, configuration, troubleshooting, and practical lab scenarios.

## Learning Path

2. Interfaces and Zones
3. Virtual Router and Routing
4. Security Policies
5. NAT
6. Application Identification
7. Security Profiles
8. IPsec VPN
9. GlobalProtect
10. Logging and Monitoring
11. Troubleshooting
12. Practical Projects

## Lab Documentation Standard

Each completed lab should contain, where applicable:

- Objective
- Network topology
- Addressing plan using lab/example IPs
- Configuration steps
- Verification commands or checks
- Expected results
- Troubleshooting notes
- Key takeaways

## Lab Safety

All configurations and examples in this repository are created for learning and lab purposes. Do not upload production credentials, private keys, customer information, internal IP addresses, proprietary configurations, or other confidential data.

## Goal

Build practical firewall and network-security skills that support a future career path toward cloud security engineering.
