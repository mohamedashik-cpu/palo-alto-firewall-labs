# Practical Projects

This section will contain complete, self-created lab projects that combine multiple Palo Alto concepts.

## Planned Projects

### Project 01 — Basic Internet Gateway

LAN → Palo Alto → Internet

Concepts: interfaces, zones, routing, security policy, source NAT, logging.

### Project 02 — Segmented Network

Users and Servers in separate security zones.

Concepts: zone segmentation, interzone policy, least privilege, application control.

### Project 03 — Site-to-Site VPN

HQ ↔ Branch using IPsec VPN.

Concepts: tunnel interface, routing, IKE/IPsec, security policy and troubleshooting.

### Project 04 — Secure Remote Access

Remote users connecting through GlobalProtect.

Concepts: portal, gateway, authentication, security policy and monitoring.

### Project 05 — Integrated Security Lab

A larger lab combining routing, NAT, security policy, Application-ID, security profiles, VPN and logging.

> All projects will use lab/example information only.
